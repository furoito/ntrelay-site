01 / OVERVIEWまず違いを知る

「まとめる」と「集計する」は、
別の作業です。

複数のExcelファイルを1つにまとめたいときは、まずデータを縦に連結したいのか、担当者・店舗・月ごとに合計したいのかを区別します。列の構成が共通しているなら、ExcelのPower Queryが有力な方法です。

A / APPEND

行を縦に追加する

店舗A・B・Cの売上明細を1つの一覧表に統合する処理。列名とデータ型を揃えることが重要です。

B / JOIN

キーで突き合わせる

顧客IDなどを基準に、別ファイルの情報を列として追加する処理。キーの重複・欠損を確認します。

C / AGGREGATE

店舗別・月別に集計する

統合したデータをピボットテーブルなどで集計。合計・件数・月別比較に利用できます。

02 / HOW TOExcelでの手順

Power Queryで
複数ファイルをまとめる

ここではWindows版Excelの一般的な操作例を紹介します。Excelのバージョンや画面構成によって表示名が異なる場合があります。

01

各ファイルの列を確認する

たとえば「日付・店舗・売上」の3列を共通にし、見出し行の位置、数値・日付の表記を揃えます。別名の列が混ざる場合は統合前に変換ルールを決めます。

02

集計対象のファイルを同じフォルダーへ入れる

月別・店舗別のExcelファイルをひとつのフォルダーにまとめます。関係のないExcelやテンポラリファイルは混ぜないようにします。

03

「データ」→「データの取得」→「ファイルから」→「フォルダーから」

対象フォルダーを指定し、一覧に対象ファイルが表示されたら、Excelの結合・変換の操作へ進みます。画面によって「結合および変換」などの名称で表示されます。

04

シート・列・データ型を確認する

サンプルファイルとして参照するシートやテーブルを選びます。日付が文字列になっていないか、列の型変換でエラーが出ていないかを確認します。

05

読み込み後、必要な集計を追加する

統合結果をテーブルへ読み込み、必要ならピボットテーブルで店舗別・月別に集計します。翌月分のファイルをフォルダーへ追加した後は、更新操作で再取得できます。

注意：元ファイルのシート構造や名前が異なる場合、フォルダーからの単純な結合だけでは正しく集計できません。列の対応や対象シート選択を調整してください。

03 / CHECK POINTSつまずきやすい点

「結合できた」だけで、
正しい集計とは限りません。

よくある問題原因の例確認・対応
列がずれる店舗ごとに列名・見出しが異なる列名の統一・不要行の削除
合計が一致しない重複行、欠損、文字列としての金額件数・合計・型変換を確認
翌月の更新で失敗新しいファイルだけシート構成が異なる入力条件を固定し、例外時の確認手順を用意
別表と照合できないキーが重複、表記が不一致顧客ID等のキーを正規化してから結合

統合した行数や金額の合計を、元ファイルの件数・集計値と突き合わせると、取り込み漏れを見つけやすくなります。

05 / FAQよくある質問

複数ファイル統合について

複数ファイルのシート名が違ってもまとめられますか？

可能な場合もありますが、単純な一括結合では対象シートの選択が合わないことがあります。シート名や列構造の違いを整理してから変換設定を調整します。

毎月ファイルが増えても更新できますか？

同じフォルダーに同形式のファイルが追加される運用なら、通常はPower Queryの更新で取り込めます。構造が変わる場合は確認が必要です。

CSVファイルにも同じ考え方を使えますか？

はい。CSVもフォルダーから読み込み、列を揃えて統合できます。ただし文字コード、区切り文字、ヘッダーの有無などを確認してください。
